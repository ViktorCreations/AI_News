# AI News — Saturday, October 31, 2026

> A week of heavy AI spending ends in a tech sell-off, with investors weighing negative free cash flow against booming cloud demand. Security is the other thread: a freely available model built working Firefox exploits for about $1,000 each.

## Top Stories

### [An open-weight model built working Firefox exploits in under 48 hours, for about $1,000 each](https://the-decoder.com/open-weight-model-glm-5-3-built-full-firefox-exploit-chains-with-zero-human-input-in-under-48-hours/)
Epoch AI researchers tested Z.ai's GLM 5.3 on the "patch gap," the time between a security fix appearing in code and reaching users. Given a Firefox version, basic tools and public information in an offline setup, the model worked out which changes were disguised security fixes and chained vulnerabilities into exploits for six Firefox versions released between 17 September and 26 October. The fastest took 12 hours; the researchers allowed up to 48.

One exploit let a web page read local files from a visitor's computer and send them to an attacker's server. The researchers say neither Z.ai nor other API providers triggered any refusal, and they describe their actions as "indistinguishable from those of someone attempting to target real users." The cost was roughly $1,000 in API fees per successful attack. This is Epoch's own test, reported by The Decoder.

### [A tampered Claude Code extension sat in Cursor's marketplace for about 11 hours](https://the-decoder.com/malicious-claude-code-extension-in-cursors-marketplace-attempted-remote-access-and-data-theft/)
Cursor says a malicious version of the Claude Code extension was available on Thursday and could have reached up to 5,000 users. It tried to collect hostname, username, operating system and public IP address, and to set up remote access for the attacker, which likely would have failed on most machines because it needs admin rights. Cursor pulled the extension, took its marketplace offline until the risk was cleared, and restored it.

Anthropic had no part in the extension, and [The Register](https://www.theregister.com/cyber-crime/2026/10/30/anthropic-that-claude-code-extension-compromise-couldnt-be-us/5306682) reports it blames a malicious actor in a targeted supply-chain attack on Cursor.

### [A Claude-based agent chose a gene therapy and operated on a mouse brain, a startup says](https://the-decoder.com/a-claude-model-autonomously-chose-a-gene-therapy-and-operated-on-a-mouse-brain-with-no-human-decision-making/)
An agent running on Claude Sonnet 5 picked the drug, brain region and injection coordinates for a mouse model of epilepsy, then ran the procedure through a motorized surgical rig. Gabriel Ocana-Santero of Exin Therapeutics says it is the first time an AI agent has both chosen a treatment and delivered it to a living mammal.

Midway through, the agent refused to continue after detecting a calibration error, which it would only have bypassed by exceeding its safety limits. The account comes from the startup, as relayed by The Decoder; no independent review is cited.
